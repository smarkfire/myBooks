## 📚 EasyAgent — 人人都能做智能体

> 你不需要写代码，只需要把需求想清楚，然后用大白话说出来。
 **[🎁 试读版](EasyAgent/人人都能做智能体.pdf)**

从一个面馆老板用智能体自动记账、生成每日经营早报的真实故事讲起，手把手带你从零搭建自己的 AI Agent。全书贯穿一个比喻：**智能体就是你雇来的超级实习生**。

**读完这本书你将学会：**

- 🧠 理解智能体的工作原理——大脑、工具、记忆、知识
- 🛠️ 用扣子（Coze）等零代码平台搭出能干活的智能体
- 🤝 设计多智能体协作，像管理团队一样管理 AI
- 🛡️ 加装防护栏，让 AI 稳定、可控、不出幺蛾子
- 💼 把智能体用到个人效率和企业业务中，附 10+ 行业真实案例

**适合人群：** 零基础小白 / 想转型的开发者 / 企业决策者 / 所有对 AI 好奇的人

### 12 章内容一览

零代码搭建 → 工具/记忆/知识 → 多智能体协作 → 防护栏与质量控制 → 编程开发 → 上下文工程与 VibeCoding → 个人效率 → 企业应用 → 10+ 行业案例 → 未来展望

## 🧠 EasyLLM — 拆解大模型：人人都能看懂 AI 的大脑

> 把一个人关进国家图书馆一年，他会变成什么？——这就是预训练。

 **[🎁试读版](EasyLLM/拆解大模型：人人都能看懂AI的大脑.pdf)**

一本把大模型讲透的科普巨著。从图灵和 ChatGPT 讲起，用"蒙着眼下山""给自习室编号""餐厅后厨分工"这些接地气的比喻，带你一步步拆开 AI 的大脑。

**这本书的独特之处：**

- 🗺️ **一条完整的知识地图**：机器学习三大范式 → 神经网络 → CNN/RNN → Transformer → LLM → Agent，65 章环环相扣，零基础也能爬到山顶
- 🎯 **比喻驱动教学**：反向传播是"错误追责的艺术"，Dropout 是"随机点名"，MoE 是"大医院的会诊制度"——每个硬核概念都有一个生活化类比
- 🔬 **不止于原理**：混合精度训练、量化剪枝、推理引擎、DeepSeek 工程实践，连"怎么让大模型又快又省"都讲明白了
- 🎁 **超值附录**：从零搭建 RAG 系统实战、面试题精选、热点技术专栏、AI 学习路线图

### 内容版图

| 模块 | 涵盖内容 |
|------|----------|
| 机器学习基础 | 监督/无监督/强化学习、概率哲学、梯度下降、过拟合 |
| 神经网络 | 感知机、反向传播、CNN、ResNet、GNN |
| NLP 与 LLM | N-gram、Embedding、注意力机制、Transformer、分词器 |
| 生成式 AI | GAN、VAE、Diffusion、Stable Diffusion、文生视频 |
| 大模型核心 | 预训练、SFT、RLHF、RAG、Agent、MCP 协议、多模态 |
| 工程与落地 | 混合精度、并行训练、MoE、量化剪枝、推理引擎、中国大模型生态 |
| 前沿与安全 | AI 安全、可解释 AI、联邦学习、具身智能、世界模型 |

> 💡 建议搭配阅读：先读 **EasyLLM** 看懂原理，再读 **EasyAgent** 动手实操。
