> 把一个人关进国家图书馆一年，他会变成什么？——这就是预训练。

**[📖 阅读 PDF（431 页 / 65 章）](拆解 AI 大模型——人人都能看懂的 AI 大脑.pdf)**

**这本书的独特之处：**

- 🗺️ **一条完整的知识地图**：机器学习三大范式 → 神经网络 → CNN/RNN → Transformer → LLM → Agent，65 章环环相扣，零基础也能爬到山顶
- 🎯 **比喻驱动教学**：反向传播是"错误追责的艺术"，Dropout 是"随机点名"，MoE 是"大医院的会诊制度"——每个硬核概念都有一个生活化类比

- 🎁 **超值附录**：从零搭建 RAG 系统实战、面试题精选、热点技术专栏、AI 学习路线图

## 🤖 开发 AI 智能体：人人都会做 AI 智能助手

> 你不需要写代码，只需要把需求想清楚，然后用大白话说出来。

**[📖 阅读 PDF](开发 AI 智能体——人人都会做 AI 智能助手.pdf)**

从一个面馆老板用智能体自动记账、生成每日经营早报的真实故事讲起，手把手带你从零搭建自己的 AI Agent。全书贯穿一个比喻：**智能体就是你雇来的超级实习生**。

**读完这本书你将学会：**

- 🧠 理解智能体的工作原理——大脑、工具、记忆、知识
- 🛠️ 用扣子（Coze）等零代码平台搭出能干活的智能体
- 🤝 设计多智能体协作，像管理团队一样管理 AI
- 🛡️ 加装防护栏，让 AI 稳定、可控、不出幺蛾子
- 💼 把智能体用到个人效率和企业业务中，附 10+ 行业真实案例

**适合人群：** 零基础小白 / 想转型的开发者 / 企业决策者 / 所有对 AI 好奇的人

### 12 章内容一览

零代码搭建 → 工具/记忆/知识 → 多智能体协作 → 防护栏与质量控制 → 编程开发 → 上下文工程与 VibeCoding → 个人效率 → 企业应用 → 10+ 行业案例 → 未来展望

## 🏢 AI 在企业落地：人人都要知道的 FDE 方法论

> 你不是在卖模型，是在交付结果。衡量标准不是"上线了没有"，而是"有没有人真的开始用了"。

**[📖 阅读 PDF（约 210 页 / 9 章 + 3 附录）](AI  在企业落地——人人都能要知道FDE方法论.pdf)**

95% 的企业 AI 项目都死在"能跑但没人用"。技术上成功、商业上无人买单——演示那天锣鼓喧天，三个月后系统安静地躺在服务器上，连个告别仪式都没有。这本书不讲技术炫技，只讲**怎么让 AI 真正在企业里活下来、用起来、产生价值**。

全书围绕一个核心角色展开：**FDE（前沿部署工程师）**——那个真正对"让 AI 在客户那里落地"负责的人。它不是技术书的续篇，更像一本**工地上的操作手册**：每一章末尾都有一张能直接照做的清单，只讲动作，不讲概念；只讲失败的细节，不吹成功的故事。

**这本书会教你：**

- 🎯 避开"概念验证坟墓"：用 PSF 找到正确的问题，用 MVD 做出尖刀而非缩水版
- 🗺️ 进场尽调五张地图：灯塔客户战略 + 行胜于言，少问"你想要什么"，多看"你现在怎么干"
- 🚀 破解"首日魔咒"：寄生于用户已经在用的东西，上线后才是开发的开始
- 💚 守住续约：用健康分在流失前预警，从守到攻扩大收入
- 📈 规模化复制：三级复制杠杆，从定制项目到平台产品
- 🧱 技术选型与本体论：RAG / Agent / 评测落地要点 + Palantir Ontology 实战
